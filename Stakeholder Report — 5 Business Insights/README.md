## Evidence basis
This report uses the previously supplied Customer CLV Analysis outputs and the strategic brief. Approved source data in the earlier project was limited to `da_sales_transactions.csv` (1,000 rows) and `da_customer_profiles.csv` (200 customers). Those original CSVs are not embedded here because they were not available as current file attachments for direct reprocessing. No substitute or synthetic transaction records were created. Aggregate values are reported as supplied; derived amounts from rounded segment shares are marked approximate.

## Key caveats
- The clustering result is 3 segments with silhouette 0.4175, not the aspirational 0.85.
- Forecast metrics are six-month revenue prediction (MAE ₹8,934.36; RMSE ₹10,831.92), not full CLV; the aspirational MAE <₹500 was not achieved.
- Segment labels are behavioural interpretations, not confirmed churn labels.
- ₹288,102.78 is an illustrative revenue scenario, not guaranteed revenue or profit.
- Category/city/channel leaders were reported, but detailed numeric breakdowns were not available in the retrieved summary.
