# Process Documentation

1. Carry forward the approved project scope: supplied sales transactions and customer profiles only.
2. Use the prior validated baseline: gross revenue, after-discount revenue, realised revenue, average transaction value, and return count/rate.
3. Use the prior RFM/K-Means outputs for segment counts, shares, and silhouette score.
4. Convert each reported finding into one stakeholder insight and a measurable action.
5. Separate observed results from illustrative campaign scenarios.
6. State modelling limitations: silhouette 0.4175; six-month revenue forecast rather than lifetime CLV; six churn flags only; profile date inconsistencies.
7. Produce PDF and editable DOCX reports, charts, and a CSV insight register.
8. Review for consistency and avoid presenting aspirational targets as achieved.
