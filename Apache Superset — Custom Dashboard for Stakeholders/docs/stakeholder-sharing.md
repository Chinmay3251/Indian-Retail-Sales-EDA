# Stakeholder Sharing Steps

## Review before sharing
- [ ] Dashboard saved and refreshed
- [ ] All five charts load without errors
- [ ] KPI definitions and date filters are clear
- [ ] Data accuracy spot-checked
- [ ] Sensitive columns/records are hidden or restricted

## Share the interactive dashboard
1. Open dashboard **Sales Overview Dashboard**.
2. Use Share/permissions controls for the intended stakeholder(s) or group.
3. Assign appropriate view access according to your Superset version and organization's security settings.
4. Copy the dashboard URL and send it to the stakeholder.
5. Confirm they can access it; do not use public sharing unless policy allows.

## Share a static PNG
1. Export screenshot or use the browser screenshot fallback.
2. Attach the PNG to your message.
3. Clearly explain that it is a static snapshot; the live dashboard has interactive filters.

## Sample stakeholder email
Subject: Sales Overview Dashboard

Hello,

Sharing the Sales Overview Dashboard for your review. It contains total revenue, category revenue comparison, monthly revenue trend, category revenue share, and product-level sales details.

The attached PNG is a static snapshot. Please use the live dashboard link to interact with the filters and explore the data.

Regards,
[Your Name]
