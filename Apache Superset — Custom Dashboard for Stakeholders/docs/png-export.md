# Dashboard PNG Export

PNG export and screenshot options vary by Superset release and configuration.

## Native dashboard screenshot (if available)
1. Open the dashboard.
2. Use the dashboard actions/menu and select screenshot/export if available in your build.
3. Wait for screenshot processing.
4. Download/save the PNG and inspect it for clipping, missing charts, or unreadable labels.

## Browser screenshot fallback
1. Open the dashboard in Chrome or Edge.
2. Set browser zoom to 80–100% so the full dashboard fits.
3. Hide navigation/sidebar if needed and ensure all charts have loaded.
4. Use browser/OS screenshot capture (Windows Snipping Tool or `Win + Shift + S`).
5. Save as `Reports/sales-overview-dashboard.png`.

## Evidence checklist
- Dashboard title is visible.
- All five chart types are present.
- KPI and chart labels are readable.
- Filters/date range are visible where relevant.
- No loading/error panels.
- PNG is saved in the project `Reports` folder (create it if needed).
