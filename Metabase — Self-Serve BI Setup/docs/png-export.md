# Dashboard PNG export

Native screenshot/export availability depends on Superset version and screenshot dependencies. If the dashboard menu provides Screenshot/Export, use it and save `Reports/sales-performance-dashboard.png`.

Fallback:
1. Open the saved dashboard in Chrome/Edge and wait for all charts to load.
2. Adjust zoom so the dashboard is legible.
3. Capture with Windows Snipping Tool (`Win + Shift + S`).
4. Save as `Reports/sales-performance-dashboard.png`.
5. Check that the dashboard title and all five charts are visible and readable.

The PNG is static; use the live dashboard URL for interactive filters.
