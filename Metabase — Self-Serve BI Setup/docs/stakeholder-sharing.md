# Stakeholder sharing

1. Refresh and save the dashboard.
2. Check filters, dates, labels, KPI definition, and data quality.
3. Remove or restrict confidential fields and records.
4. Configure dashboard permissions for the intended stakeholders with view access.
5. Copy the dashboard URL and test access with an authorized viewer.
6. Send the URL with a short explanation of metrics, filters, and refresh timing.
7. Attach `Reports/sales-performance-dashboard.png` as a static snapshot.
8. Do not enable public access unless organizational policy approves it.
