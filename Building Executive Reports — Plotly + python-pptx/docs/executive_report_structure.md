# Executive Report Structure

- **Executive summary:** headline, reporting period, decision required.
- **KPI scorecard:** revenue, profit, margin, and orders with units.
- **Performance trend:** revenue and profit over time.
- **Business breakdown:** category contribution and profitability.
- **Recommendations:** action, owner, and success measure.

Design principles: one message per slide; takeaway-led titles; readable charts; clear labels; distinguish facts from interpretation; avoid causal claims from descriptive data; include the data period and limitations.
