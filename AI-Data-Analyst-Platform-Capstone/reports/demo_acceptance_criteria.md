# Demo Acceptance Criteria

- [ ] App launches locally in Streamlit
- [ ] KPI cards display non-empty values
- [ ] Region question returns a result table and chart
- [ ] Monthly trend question returns a time series result
- [ ] Generated SQL is visible to the presenter
- [ ] SQL guard rejects write operations
- [ ] CSV download works
- [ ] Optional Ollama mode tested, or clearly disclosed as not enabled
- [ ] Demo completes within three minutes
- [ ] Synthetic dataset is identified as synthetic
