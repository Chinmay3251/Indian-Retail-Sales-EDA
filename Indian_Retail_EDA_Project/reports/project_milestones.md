# Four-Week Project Milestones

## Week 1 — Setup and requirements
- Set up Python and install Pandas, NumPy and Matplotlib.
- Review business questions, dataset columns and initial data quality.

## Week 2 — Core EDA
- Clean duplicate and missing values.
- Create date and margin features; calculate KPIs.
- Analyze sales by category, city, channel and month; create charts.

## Week 3 — Testing, debugging and CIA-assisted review
- Run the analysis script and data-quality tests.
- Check calculations, labels, assumptions and whether conclusions are supported.
- CIA-assisted review is treated as a review checklist, not external certification.

## Week 4 — Final polish and submission
- Finalize the five-finding report, README and folder structure.
- Verify outputs and prepare the project package for submission.
